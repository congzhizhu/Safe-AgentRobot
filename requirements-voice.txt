# ============================================================================
# 语音功能可选依赖（机器狗语音交互）
# ----------------------------------------------------------------------------
# 必装：
#   sounddevice —— 麦克风录音 / 扬声器播放（wheel 自带 PortAudio，无需额外装库）
#   soundfile   —— 解码 mp3 / wav 音频流
#
# 语音合成（TTS）三选一，按你的部署环境挑：
#   edge-tts    —— 免费、无需 Key、音色自然，推荐（需联网）
#   pyttsx3     —— 完全离线，音色机械，适合无网车间
#
# 语音识别（ASR）二选一，离线环境建议装：
#   dashscope   —— 百炼云端 ASR（qwen3-asr-flash），bailian 方案必装
#   funasr      —— 阿里开源，Paraformer / SenseVoice，中文效果好
#   openai-whisper —— 通用多语言，离线可用
# ============================================================================
