# 机器狗服务启动步骤

> 每次要控制机器狗巡检时，按下面三步走即可。

---

## 前提（每次启动前确认）

1. **狗已开机**，网线已插好（狗 RJ45 网口 ↔ 电脑网口）
2. **电脑网卡 IP 是 `192.168.123.222`**（之前已配好，一般不用动）

---

## 第一步：先检查服务是否已经在跑（避免端口冲突）

打开 **Windows PowerShell**，执行：

```powershell
curl.exe http://127.0.0.1:8010/health
```

**看结果判断：**

- 返回 `{"ok": true, ...}` → **服务已经在跑，直接用，跳过第二步**，直接去开网页
- 报「无法连接」/ 超时 → 服务没跑，继续第二步

---

## 第二步：进入 WSL 并启动服务

在 **Windows PowerShell** 里执行：

```powershell
wsl -d Ubuntu-22.04 -u zzc
```

进入 WSL 后，执行：

```bash
cd /mnt/d/Safety_Agent/robot && python3 robot_service.py --nic auto --port 8010
```

看到这两行就是**启动成功**：

```
[连接] ✅ SportClient 就绪，狗应该可以被控制
[服务] 监听 http://127.0.0.1:8010  （Ctrl+C 停止）
```

> **注意**：这个 WSL 窗口要**一直开着**，它是控狗服务。
> 关掉窗口 = 服务停止。

---

## 第三步：打开智能体网页

浏览器打开 **http://127.0.0.1:7860** →

进入「🤖 机器狗巡检」面板 → 点「🔄 刷新连接状态」，

看到 🟢 已连接即可开始巡检。

---

## 遇到「端口被占用」怎么办

如果第二步报 `Address already in use`，说明有残留进程，先在 WSL 里执行：

```bash
fuser -k 8010/tcp
```

然后再重新执行第二步的启动命令。

---

## 一句话总结

```
检查(8010/health) → 启动(wsl + robot_service.py) → 开网页(7860)
```
