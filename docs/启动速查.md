# 启动速查

> 智能体 + 控狗服务完整启动步骤，按顺序执行即可。

---

## 启动前确认（一次性，一般已配好）

1. 狗已开机，网线插好（狗 RJ45 网口 ↔ 电脑网口）。
2. 电脑网卡 IP 是 `192.168.123.222`（之前配好，一般不用动）。
3. `.env` 文件里已填入阿里云百炼 API Key（`QWEN_API_KEY=sk-...`）。若没填，启动会直接报错退出。

---

## 第一步：启动控狗服务（WSL 侧）

打开 **Windows PowerShell**，先检查服务是否已在跑：

```powershell
curl.exe http://127.0.0.1:8010/health
```

- 返回 `{"ok": true, ...}` → 服务已在跑，跳过下面，直接去第三步。
- 报「无法连接」/ 超时 → 继续。

进入 WSL：

```powershell
wsl -d Ubuntu-22.04 -u zzc
```

在 WSL 里执行：

```bash
cd /mnt/d/Safety_Agent/robot && python3 robot_service.py --nic auto --port 8010
```

看到这两行即**控狗服务启动成功**：

```
[连接] ✅ SportClient 就绪，狗应该可以被控制
[服务] 监听 http://127.0.0.1:8010  （Ctrl+C 停止）
```

> 这个 WSL 窗口要**一直开着**，它是控狗服务；关掉窗口 = 服务停止。

---

## 第二步：启动智能体（Windows 侧，另开一个 PowerShell 窗口）

```powershell
cd D:\Safety_Agent
.venv\Scripts\python.exe start_all_windows.py
```

这个一键脚本会自动拉起两个服务：
- 知识库管理 API（`http://127.0.0.1:8001`）
- Agent WebUI（`http://127.0.0.1:7860`）

看到以下输出即成功：

```
[1/2] 启动数据入库与知识库管理 API (http://127.0.0.1:8001) ...
[2/2] 启动 Agent WebUI (http://127.0.0.1:7860) ...
```

> 首次启动 WebUI 会下载 BGE/CLIP 模型，需耐心等几分钟。这个窗口也要**一直开着**，停止用 `Ctrl + C`。

---

## 第三步：打开网页，确认狗已连接

浏览器打开 **http://127.0.0.1:7860**，进入「机器狗巡检」面板，点「刷新连接状态」，看到 🟢 已连接即完成。

---

## 一句话速查

```
检查(8010/health) → 启动狗(WSL: robot_service.py) → 启动智能体(Windows: start_all_windows.py) → 开网页(7860)
```

---

## 常见问题速查表

| 现象 | 处理 |
|------|------|
| `start_all_windows.py` 报「未配置 QWEN_API_KEY」 | 在 `.env` 填入 `sk-` 开头的 Key |
| 报「端口已被占用 8001/7860」 | 已有一个实例在跑，直接用 `http://127.0.0.1:7860`，或关旧窗口后重跑 |
| WSL 报 `Address already in use`（8010 被占） | WSL 里执行 `fuser -k 8010/tcp` 再重跑 |
| 网页里狗显示未连接 | 回到第一步确认 `curl http://127.0.0.1:8010/health` 是否返回 ok |
| 控狗服务启动时「SportClient 初始化失败」 | 检查网线是否插好、狗是否开机、`ip -br addr` 是否有 `192.168.123.222` |
